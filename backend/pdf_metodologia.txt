
===== PAGINA 1 =====
ESTRUCTURA DE DESARROLLO DEL MVP (PLATAFORMA) 
La intervención se establece como un ciclo pedagógico adaptativo estudiante –IA, donde la innovación no 
proviene de agregar funciones, sino de establecer una secuencia reproducible, reglas explícitas de decisión 
y niveles graduados de andamiaje usando exclusivamente información que el formulario ya contempla. 
El d iseño se mantiene: diagnóstico inicial, actividades guiadas, resolución de problemas, 
retroalimentación automática, apoyo tutorial mediante IA, adaptación dinámica según desempeño, 
metacognición, seguimiento del progreso y evaluación preliminar.  
El formulario establece explícitamente las variables de : adaptación del desempeño diagnóstico, error 
conceptual, error procedimental, número de intentos, avance, solicitud de ayuda, cambio de desempeño y 
tiempo de interacción. 
1. Principio metodológico 
Nombre: Ciclo de Aprendizaje Adaptativo Mediado por IA (CAAMI). 
1.1. El protocolo científicamente es: 
𝐷𝑖𝑎𝑔𝑛𝑜𝑠𝑡𝑖𝑐𝑎𝑟 → 𝑅𝑒𝑠𝑜𝑙𝑣𝑒𝑟 → 𝐷𝑒𝑡𝑒𝑐𝑡𝑎𝑟 → 𝐴𝑛𝑑𝑎𝑚𝑖𝑎𝑟 → 𝑅𝑒𝑖𝑛𝑡𝑒𝑛𝑡𝑎𝑟 → 𝑉𝑒𝑟𝑖𝑓𝑖𝑐𝑎𝑟 → 𝑅𝑒𝑓𝑙𝑒𝑥𝑖𝑜𝑛𝑎𝑟 → 𝑃𝑟𝑜𝑔𝑟𝑒𝑠𝑎𝑟  
1.2. La regla transversal es: 
La IA entrega el menor nivel de apoyo suficiente para permitir siempre un nuevo intento  
El estudiante no recibe automáticamente una solución completa ante un error . Se establece que el error 
procedimental puede producir una pista o secuencia guiada, que el número de intentos puede activar ayuda 
gradual y que una solicitud voluntaria puede producir una pista, explicación o ejemplo.

4. Reglas de decisión por programar  
Se debe evitar que el LLM  “decida pedagógicamente” de manera libre. La plataforma deberá controlar la 
política de andamiaje, mientras que la IA genera la intervención correspondiente. 
La versión mínima viable será: 
Respuesta correcta ⇒ 𝐹5 
Error en intento 1 ⇒ 𝐴1 
Error después de A1 ⇒ 𝐴2 
Error después de A2 ⇒ 𝐴3 
Error después de A3 ⇒ 𝐴4 
Error después de A4 ⇒ 𝐴5 
La solicitud explícita de ayuda  permite activar el nivel correspondiente sin obligar a acumular respuestas 
incorrectas innecesariamente. Ante un error conceptual/procedimental inequívoco, A2 puede focalizar 
directamente la pista en ese error. 
Después de A5: 𝐴5 ⇒ actividad comparable de verificación 
No es: 𝐴5 ⇒ actividad superada 
Este punto es fundamental, ya que recibir una solución no constituye evidencia de aprendizaje. 
 
5. Qué decide el algoritmo y qué decide la IA generativa 
5.1. Motor pedagógico determinista 
Decide: A1 / A2 / A3 / A4 / A5 
y: avanzar / verificar / reforzar / repasar prerrequisito. 
Utiliza solamente: {𝒅𝒆𝒔𝒆𝒎𝒑𝒆ñ𝒐, 𝒆𝒓𝒓𝒐𝒓,  𝒊𝒏𝒕𝒆𝒏𝒕𝒐𝒔,  𝒂𝒗𝒂𝒏𝒄𝒆,  𝒔𝒐𝒍𝒊𝒄𝒊𝒕𝒖𝒅 𝒅𝒆 𝒂𝒚𝒖𝒅𝒂,  𝒄𝒂𝒎𝒃𝒊𝒐 𝒅𝒆 𝒅𝒆𝒔𝒆𝒎𝒑𝒆ñ𝒐} 
Por lo tanto, el motor pedagógico controla la decisión y el LLM controla principalmente la generación de 
la respuesta. 
===== PAGINA 5 =====
5.2. IA generativa 
No decide libremente la estrategia; recibe una instrucción estructurada como: 
Actividad (X) + respuesta del estudiante + error conceptual identificado + nivel A2 + contenido 
autorizado. 
Y su función es generar: una pista conceptual específica de nivel A2. 
Esto permite hacer la intervención reproducible y auditable. 
Dos estudiantes pueden recibir textos distintos, pero ambos están recibiendo el mismo tratamiento 
pedagógico A2.

Hay que considerar que tanto A1-A5 no necesitan tratarse como cinco nuevas variables educativas . Son

7. NO incorporar al MVP 
Por ahora NO incorporar: 
• perfil cognitivo generado por IA; 
• estilo de aprendizaje; 
• nivel de inteligencia; 
• motivación inferida; 
• atención inferida por tiempo; 
• estado emocional; 
• personalidad; 
• “dependencia de IA” como diagnóstico del/la estudiante; 
• clasificación permanente en nivel bajo/medio/alto; 
• predicción automática de riesgo académico.
